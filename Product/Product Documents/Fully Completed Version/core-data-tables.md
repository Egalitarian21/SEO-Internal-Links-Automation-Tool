# Core Data Tables

| Table | Purpose |
|------------|-------------|
| `imported_blog_urls` | Stores manually imported Sitemap blog URLs. |
| `blog_drafts` | Stores crawled blog titles, body text, HTML, and Meta information. |
| `wiki_cards` | Stores Wiki knowledge cards generated by the LLM from blogs. |
| `anchor_suggestions` | Stores internal-link anchor text suggestions for a specific blog post. |
| `review_tasks` | Stores the status of manual review tasks. |
| `shopify_publish_jobs` | Stores tasks and results for publishing to Shopify. |
