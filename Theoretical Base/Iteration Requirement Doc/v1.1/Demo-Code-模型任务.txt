## 模型任务

### 1. 页面语义画像生成

| 页面主题识别 | 根据页面 title、outline、excerpt 判断页面 primary_topic 和 secondary_topics。 |
| 页面摘要生成 | 为站内页面生成简洁摘要，供后续匹配和报告使用。 |
| 搜索意图判断 | 判断页面属于 informational、commercial、transactional、navigational 等意图。 |
| 页面类型判断 | 判断页面是 blog、guide、service、product、category、case study、documentation 等类型。 |
| 受众阶段判断 | 判断页面更偏 awareness、middle_funnel、bottom_funnel 或 post_purchase。 |
| 实体抽取 | 抽取页面中重要的品牌、工具、概念、标准、人物、组织等实体。 |
| 关键词生成 | 生成页面的主关键词和辅助关键词。 |
| 可链接概念提取 | 判断该页面适合作为哪些概念的内部链接目标。 |


### 2. 博客语义画像生成

| 博客主题识别 | 判断导入博客的核心主题和辅助主题。 |
| 博客摘要生成 | 为导入博客生成简洁摘要，便于后续匹配。 |
| 博客搜索意图判断 | 判断博客面向的信息需求、商业需求或转化需求。 |
| 博客目标受众判断 | 判断博客面向初学者、专业用户、买家、开发者或其他受众。 |
| 博客实体抽取 | 抽取博客中出现的重要概念、工具、标准、品牌和专业术语。 |
| 博客可链接概念提取 | 找出博客中值得添加内部链接或外部链接的概念。 |
| 链接类型初判 | 对可链接概念初步判断更适合 internal、external 或 both。 |


### 3. 锚文本生成与优化

| 自然锚文本生成 | 根据上下文生成自然、不生硬的锚文本候选。 |
| 锚文本类型判断 | 判断锚文本属于 exact match、partial match、contextual phrase、entity 或 branded。 |
| 锚文本自然度评分 | 判断锚文本放在当前句子中是否自然流畅。 |
| 锚文本风险判断 | 识别过度优化、关键词堆砌、过泛或误导性锚文本。 |
| 锚文本改写建议 | 将生硬关键词改写为更自然的上下文短语。 |


### 4. 内部链接语义复核

| 内链相关性判断 | 判断某个锚文本上下文与候选站内页面是否真正相关。 |
| 最佳内链目标选择 | 在多个候选站内页面中选择最适合的目标页面。 |
| 内链关系类型判断 | 判断链接关系属于 supporting topic、parent topic、related topic、commercial path 等。 |
| 内链方向判断 | 判断当前博客是否适合链接到候选页面。 |
| 内链推荐理由生成 | 生成为什么推荐该内部链接的简洁解释。 |
| 内链置信度评分 | 为模型判断的内部链接推荐给出 confidence 分数。 |


### 5. 外部链接权威性复核

| 外链必要性判断 | 判断当前上下文是否真的需要外部权威链接。 |
| 外链候选选择 | 在脚本提供的外部资源候选中选择最适合的 URL。 |
| 外链来源类型判断 | 判断外链属于官方文档、行业标准、统计来源、工具文档还是研究报告。 |
| 外链上下文匹配 | 判断外链是否能支持当前段落中的定义、数据、标准或声明。 |
| 外链推荐理由生成 | 解释为什么该外部来源适合作为引用或补充阅读。 |
| 外链置信度评分 | 为外链推荐结果提供 confidence 分数。 |


### 6. 最终推荐质量检查

| 推荐自然性复核 | 检查最终推荐链接是否会破坏文章阅读体验。 |
| 推荐重复性复核 | 检查是否存在语义重复、目标重复或锚文本重复。 |
| 外链比例合理性判断 | 判断外链是否过多或不必要。 |
| 内链覆盖合理性判断 | 判断是否覆盖了文章中最重要的站内链接机会。 |
| SEO 风险提醒 | 提醒可能存在过度优化、商业链接过强或外链不权威的问题。 |
| 最终解释生成 | 为用户生成简洁的推荐总结和优化建议。 |
