## 内链自动化流程总览

### 阶段 1：项目初始化与站点数据库构建
用户创建项目 → 导入 sitemap → 脚本爬取页面 → 清洗抽取 → 技术 SEO 检查 → 模型分析 → 存入数据库 → 建立站内语义索引

### 阶段 2：博客导入与链接推荐
用户导入博客 → 脚本解析博客 → 模型理解博客 → 提取可链接概念和锚文本候选 → 判断站内/外链 → 匹配站内页面或推荐外部权威链接 → 生成最终推荐

#### 2.5 判断使用内部链接还是外部链接(脚本)

对每个锚文本候选，系统判断：
"""
是否有高度匹配的站内页面？
    是 → 优先推荐内部链接
    否 → 是否属于需要权威来源的概念？
        是 → 推荐外部链接
        否 → 不推荐链接或降低优先级
"""

具体的判断逻辑:
"""
1. 查询项目站内页面库
2. 如果存在高相关页面，优先内部链接
3. 如果站内页面相关度一般，但该概念是标准/政策/官方文档/统计数据，则考虑外链
4. 如果是竞争性商业关键词，不推荐外链到竞争对手
5. 如果该段落已有链接，降低优先级
6. 如果锚文本过于泛化，降低优先级
7. 如果目标页面 noindex/404/canonical 到其他 URL，禁止推荐
"""

将需要添加内部链接的候选锚文本整理到"internal_links"excel表格, 存放在"C:\Users\yiguo\Desktop\Internal Link Tool\Demo\Data\[brand_name]\recommendations\[blog_id]\text_candidate"

将需要添加外部链接的候选锚文本整理到"external_links"excel表格, 存放在"C:\Users\yiguo\Desktop\Internal Link Tool\Demo\Data\[brand_name]\recommendations\[blog_id]\text_candidate"

#### 2.7 内部链接推荐(脚本 + 模型API)

总体采用 "规则约束的脚本 + 模型判断"的工作流

Step 1: 脚本召回候选锚文本

1. 召回来源与规则：
- page_profile: 主题、关键词、搜索意图匹配
- page_embeddings: 语义相似度匹配
- normalized_pages: title、H1、URL、正文匹配
- technical_seo_audits: 过滤不可推荐页面
- internal_link_graph: 避免重复链接
- 链接规则："C:\Users\yiguo\Desktop\Internal Link Tool\Demo\Code\config\link_rule.yaml"

2. 内部链接评分
** similarity_score = 语义相似度 × 0.35 + 关键词匹配 × 0.20 + 页面质量 × 0.15 + 搜索意图匹配 × 0.10 + 页面商业价值 × 0.10 + 是否未被当前博客链接 × 0.10 **

|          分数 | 决策        |
| ----------: | --------- |
|     >= 0.80 | 强推荐内部链接   |
| 0.65 - 0.79 | 可推荐，需模型复核 |
| 0.50 - 0.64 | 弱相关，不优先   |
|      < 0.50 | 不推荐       |


3. 召回结果示例:
"""JSON
{
  "anchor_text": "technical SEO audit",

      "similarity_score": 0.91,

      "already_linked": false
    },

      "page_id": "page_014",

      "title": "Best SEO Audit Tools",

      "page_quality_score": 0.88,
      "already_linked": false
    }
  ]
}
"""
