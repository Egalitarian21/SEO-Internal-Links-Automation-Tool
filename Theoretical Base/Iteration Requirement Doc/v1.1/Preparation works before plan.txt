1.1 链接规则
| 规则                | 说明                 |
| ----------------- | ------------------ |
| 不重复推荐同一个 URL      | 一篇文章中同一目标 URL 最多一次 |
| 不重复相同锚文本          | 避免过度优化             |
| 不推荐已有链接           | 已经链接过则跳过           |
| 不推荐 noindex 页面    | 内链目标必须可索引          |
| 不推荐 404/重定向页面     | 保证链接质量             |
| 每个段落最多 1 个链接      | 避免密集插链             |
| 每个 section 限制链接数量 | 保持阅读体验             |
| 外链比例限制            | 防止过多外链             |
| 商业页面限制            | 避免强行推荐产品页          |
| 锚文本自然性检查          | 避免生硬关键词堆砌          |


1.2 适合推荐外部链接的锚文本类型:
| 场景         | 示例                               |
| ---------- | -------------------------------- |
| 官方定义       | Google Search Central、Schema.org |
| 行业标准       | W3C、IETF、ISO                     |
| 统计数据       | 原始报告、研究机构                        |
| 工具说明       | 官方工具文档                           |
| 法律/医疗/金融内容 | 政府、监管机构、权威组织                     |
| 技术规范       | MDN、Google Developers、web.dev    |

1.3 链接数量控制
|        文章长度 |  总链接数 |   内链 |  外链 |
| ----------: | ----: | ---: | --: |
|     < 800 字 |   2–4 |  2–3 | 0–1 |
|  800–1500 字 |   4–6 |  3–5 |   1 |
| 1500–2500 字 |  6–10 |  5–8 | 1–2 |
|     2500+ 字 | 10–15 | 8–12 | 2–3 |
 默认比例: 
- 内部链接：70%–85%
- 外部链接：15%–30%
